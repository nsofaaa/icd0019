ICD0019 – Java Programming 
(TalTech)
Coursework for ICD0019, the Java 
programming course in the IT Systems 
Development programme at Tallinn University of
Technology (TalTech).
The repository contains my solutions to the 
weekly exercises, from language basics to 
object-oriented design, generics, functional 
programming and reflection. Most exercises 
come with JUnit 5 tests (with AssertJ 
assertions) that check the solution.
Highlights
Topics covered
Basics – intro, jvm
Object-oriented programming – oo, hide, 
inheritance
Unit testing – junit, tests next to most 
exercises
Exceptions and localisation – exceptions 
(number-to-words in several languages using
.properties files)
Collections – collections (sets, maps, 
sorting with comparators, caching, 
hashCode/equals)
Generics – generics (own list and stack 
implementations, converters, wildcards, 
recursion)
Functional programming – fp (streams, map
/ filter / reduce, Optional, grouping)
Reflection – reflection
Other – bonus/pager (paging and filtering)
Tech
Java
JUnit 5, AssertJ (jars in lib/)
IntelliJ IDEA
How to run
Open the project in IntelliJ IDEA, add the jars 
from lib/ as project libraries, then run any 
Runner / Main class or the test classes 
(*Test.java, *Tests.java).
